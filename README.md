# Console App for .ton Domain Renewal

Консольное приложение для проверки сроков действия доменов `.ton` и продления тех, до истечения которых осталось меньше заданного порога. Управление через пошаговое текстовое меню в терминале.

## Почему это нужно

Домены `.ton` представляют собой NFT-контракты с ограниченным сроком действия. В популярных кошельках продление выполняется только вручную, поэтому домен легко потерять, если забыть о нём.

## Tech Stack

- **Python 3.11+**: язык проекта
- **`tonutils`**: SDK для работы с TON
- **`questionary`**, **`rich`**: терминальный интерфейс
- **`python-dotenv`**: загрузка конфигурации и настроек из `.env`

## Возможности

- Интерактивное меню для управления списком доменов и настройками
- Проверка даты истечения доменов `.ton`
- Автоматическое продление при достижении заданного порога
